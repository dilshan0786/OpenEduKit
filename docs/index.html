Integration Documentation

Integrate OpenEduKit.js directly into your HTML pages with simple script source tags:

1. Dynamic OMR Sheet Generator API

// Initialize OMR generation with customizable meta blocks and series lists
OpenEduKit.generateOMR({
  containerId: 'omr-container',
  boardTitle: 'WEST BENGAL JOINT ENTRANCE EXAMINATIONS BOARD',
  examTitle: 'SAMPLE OMR SHEET',
  metaFields: ['Student Name', 'Roll Number', 'Subject'],
  logoUrl: 'path/to/logo.png',
  showRollNumber: true,
  rollNumberDigits: 10,
  showBarcode: true,
  showSeries: true,
  seriesList: ['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H', 'I', 'J'],
  seriesLetter: 'A',
  totalQuestions: 100,
  optionsPerQuestion: 4,
  columns: 5,
  interactive: true
});

2. JSON-Driven Quiz Module API

// Setup interactive digital quiz
const engine = new OpenEduKit.QuizEngine({
  containerId: 'quiz-container',
  quizData: {
    quizTitle: "Science Exam",
    questions: [
      { id: 1, questionText: "Water formula?", options: ["H2O", "CO2"], correctAnswerIndex: 0 }
    ]
  },
  onComplete: (responses) => {
    console.log("Responses submitted:", responses);
  }
});
engine.init();

3. Scorecard & Response Analyzer API

// Grade responses and display reports
const report = OpenEduKit.analyzeExam(questionsList, studentResponses);
console.log(report.percentage); // e.g. 85.5

// Render report scorecard to dashboard
OpenEduKit.renderReportHTML('report-container', report);
